# Site brief

This project is a single-page website. The whole site is `index.html`.

## Rules

- Keep everything in `index.html` — inline the CSS and any JavaScript. Do not
  create extra pages, build steps, or a framework.
- Keep it responsive and readable on a phone.
- Keep the page fast: no heavy libraries, no large images.
- After each change, the preview reloads automatically. Describe what you
  changed in one short sentence.
